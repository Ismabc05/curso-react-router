📘 React Router Demo

Este proyecto es un ejemplo de una aplicación React utilizando React Router v7 para manejar rutas y navegación dentro de la aplicación. Incluye autenticación simulada, rutas protegidas y navegación entre páginas.

🚀 Tecnologías usadas

- React 18

- React Router DOM 7

- Vite como herramienta de build

- JavaScript (ES6)
